# Liquen Panel

Plugin de WordPress: back office en el front para cargar contenidos desde el celular. Detalles en `readme.txt`.

## Publicar una versión nueva

1. Subir los cambios con el número nuevo en `liquen-panel.php` (en `Version:` y en `LP_VERSION`) y una línea en «Cambios» de `readme.txt`.
2. Releases → **Draft a new release** → etiqueta `vX.Y.Z` (el mismo número) → **Publish release**.
3. GitHub arma solo `liquen-panel.zip` y lo adjunta (pestaña Actions, ~1 min). Los sitios ven la actualización en unas horas, o al instante con Escritorio → Actualizaciones → «Volver a comprobar».

Para instalar a mano, usar ese `liquen-panel.zip` de la release, nunca «Source code».
